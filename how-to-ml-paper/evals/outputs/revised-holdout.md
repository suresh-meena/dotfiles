We keep the classifier fixed throughout and calibrate its logits $z(x)$ using the sensor-group label $g$, which is known at inference. Temperature scaling divides logits by a fitted positive scalar before applying softmax \cite{guo2017calibration}. GroupCal makes this temperature group-specific: for each group with at least 50 held-out validation examples, we fit $T_g>0$ by minimizing negative log-likelihood on that group's examples. Only the calibration parameters change; the classifier architecture and feature representation remain fixed.

Rare groups provide fewer examples for fitting a separate temperature. For any group with fewer than 50 validation examples, we therefore use a shared positive temperature fitted on the full validation set. We fixed this threshold before test evaluation. At inference, we select the group-specific or shared temperature using $g$, divide $z(x)$ by that temperature, and apply softmax to obtain class probabilities. Fitting uses no test labels.
