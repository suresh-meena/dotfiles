GroupCal calibrates the logits \(z(x)\) of a frozen classifier using a sensor-group label \(g\) available at inference time. Ordinary temperature scaling divides logits by a fitted positive scalar before applying softmax \cite{guo2017calibration}. We extend this procedure by fitting a separate positive temperature \(T_g\) for each group. We fit each temperature by minimizing negative log-likelihood on held-out validation examples from its group. The classifier weights and feature representation remain fixed throughout calibration.

Rare groups have fewer examples available for fitting. For a group with fewer than 50 validation examples, we use one shared positive temperature fitted on the full validation set. We fixed this threshold before test evaluation. At inference, the input's group label determines which fitted temperature to use. We divide \(z(x)\) by this temperature before applying softmax to obtain class probabilities. No test labels are used to fit the calibration parameters.
