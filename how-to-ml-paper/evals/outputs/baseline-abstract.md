We investigate whether token-dependent block skipping can reduce inference latency in decoder-only transformers while limiting accuracy loss. SkipGate uses a small learned gate to inspect the current hidden state and decide whether to execute each transformer block or bypass it through its residual path. Fine-tuning combines the task loss with a penalty on the number of executed blocks. We evaluate one 7B model on MMLU, GSM8K, ARC-C, and HellaSwag using one GPU type at batch size one. Methods receive equal fine-tuning data and 12 tuning trials each, with accuracy averaged across five independent fine-tuning seeds. SkipGate reduces median end-to-end latency from 42 to 29 ms/token, including gating overhead, a 31% reduction under matched measurement conditions. Mean task accuracy decreases from 63.8% to 63.5%. A static-depth baseline matched on the average number of executed blocks achieves 61.9% accuracy at 27 ms/token. SkipGate therefore achieves higher observed accuracy than static depth with 2 ms/token additional latency in this setting. Accuracy equivalence to the dense baseline remains unestablished because uncertainty intervals were not computed.

- Claims of priority require a literature comparison.
- The gate's contribution needs an ablation. The proposed explanation involving redundant reasoning remains untested.
- Broader generalization remains untested beyond this model and device at batch size one. Throughput and energy savings were not measured.
