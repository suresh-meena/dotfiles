# Fleet hardening material

[fleetctl-hardening-prompt.txt](fleetctl-hardening-prompt.txt) is a proposed
hardening brief. Its broader implementation has not been completed.

The supplied `AMD Server.pdf` is retained locally and ignored by Git because
it includes private connection information. Its SHA-256 and reusable site
rules are recorded in the
[AMD cluster reference](../shared/fleet-dotfiles/codex/skills/remote-fleet-operator/references/amd-gpu-cluster.md).
That reference is sufficient for using the installed skill without the PDF.

The documented hardware, software versions, and sample requests do not
establish current fleet availability or authorize changes to live hosts.
